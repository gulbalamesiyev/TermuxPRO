# Termux Shared Library

A library containing common utilities, constants, and helper classes used by all Termux Pro modules.

## 📦 Contents

- **TermuxConstants**: Centralized definitions for file paths, intent actions, and permission names.
- **ShellUtils**: Helpers for executing commands and managing environment variables.
- **Logger**: Standardized logging utility for the entire project.

## 🛠️ Usage

This module is a dependency for almost every other module in the project.
