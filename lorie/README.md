# Lorie Renderer Module

Lorie is the high-performance X11 renderer core for Termux Pro. It handles the display of graphical Linux applications by providing a bridge between X11 and Android's Surface.

## 🚀 Features

- Native X11 protocol implementation.
- GPU-accelerated rendering.
- Touch and mouse input handling for X11 sessions.

## 🏗️ C++ Core

The module contains a significant amount of native C++ code in `src/main/cpp`, including recipes for building various X11 components.
